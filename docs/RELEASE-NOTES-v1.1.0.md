# TheToolTable v1.1.0

Personal multi-tool studio: 20 utilities, with responsive Material-style UI and the completed repair/hardening pass.

## Installers

- **Android:** `TheToolTable.apk` — signed APK built for 64-bit ARM and ARMv7 Android devices.
- **Windows:** `TheToolTable_*_x64-setup.exe` (per-user NSIS installer) and `TheToolTable_*_x64_en-US.msi`.

The Windows installers include the yt-dlp, FFmpeg, and FFprobe sidecars required by the Downloader. The Windows downloader runs on the PC; use it only for content you own or are authorized to save.

The Android APK does not bundle a native yt-dlp runtime. To use Downloader on Android, configure a network-reachable HTTPS companion engine in the Downloader screen; the rest of the tools work without that engine. Models, current currency rates, and optional map lookups may need an internet connection.

This repository is private, so these release downloads are available only to accounts with repository access. The app is for personal use; review each service’s terms and applicable law before downloading media.
